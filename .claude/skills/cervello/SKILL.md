# Cervello

All'inizio: `cervello/LEGGIMI.md` → `REGOLE.md` (vincolante) → `MAPPA.md` → voci di `BUG.md` e
`LEZIONI.md` sulla parte da toccare.

Alla fine, prima di rispondere:
- bug trovato o corretto → `BUG.md` (causa vera + nome del test);
- strada sbagliata presa → `LEZIONI.md` (regola pratica, una riga o due);
- idea per aspetto/semplicità/guide → `IDEE.md` con priorità A/B/C;
- scoperta su com'è fatto il progetto → `MAPPA.md`;
- una riga in `DIARIO.md`: data — chi — cosa — esito collaudo — commit.

Mai cancellare voci: si chiudono con data e commit. Il cervello si committa insieme al lavoro.
