📖 Guida — Come ottenere le credenziali Capital.com

1. Accedi al tuo conto Capital.com da browser (non serve l'app mobile) con l'email e la password del tuo account — apri qui la pagina di login ↗.

2. Vai su Impostazioni → sezione "Integrazioni API".

3. Attiva il 2FA se non l'hai già fatto: è obbligatorio per poter generare una API Key.

4. Clicca su "Genera chiave API". Nella finestra che si apre: dai un nome alla chiave, imposta una password personalizzata per la API Key (è diversa dalla password del tuo account — sarà quella da inserire qui nel campo "Password della API Key") ed eventualmente una scadenza (di default dura 1 anno).

5. Inserisci il codice 2FA quando richiesto e conferma.

6. Copia subito la API Key mostrata: viene mostrata una sola volta, se la perdi dovrai generarne una nuova.

7. Torna qui e inserisci: la tua email di accesso Capital.com, la API Key appena copiata, e la password della API Key scelta al punto 4.

💡 Suggerimento: se vuoi solo provare senza rischiare soldi veri, Capital.com permette di generare una API Key anche per un conto demo gratuito — le credenziali si inseriscono allo stesso modo.
