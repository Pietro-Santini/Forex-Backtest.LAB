SYNTRA - DIAGNOSI CON BLUESTACKS, PASSO PASSO
=============================================
Scopo: capire se il PC riesce a LEGGERE come testo la schermata di Syntra (utente, asset,
entrata, TP, SL). Lo script legge e basta: non tocca, non clicca, non manda niente a nessuno.
Tempo: 20-30 minuti la prima volta.


PASSO 1 - INSTALLA BLUESTACKS 5
-------------------------------
1. Installa BlueStacks 5 (versione con Android 11 o piu' recente, se te la fa scegliere: 64 bit).
2. Aprilo e accedi con il tuo account Google (come su un telefono nuovo).
3. Apri il Play Store dentro BlueStacks, cerca Syntra, installala.
4. Apri Syntra e fai il login.
   -> Se Syntra NON si apre, si chiude da sola o dice "dispositivo non supportato / rooted /
      emulatore": FERMATI e scrivimelo con il messaggio esatto. Vuol dire che blocca gli
      emulatori, e si cambia strada (altro emulatore o telefono dedicato).


PASSO 2 - ATTIVA ADB IN BLUESTACKS
----------------------------------
ADB e' il "cavo" con cui il PC parla con Android.
1. In BlueStacks clicca l'ingranaggio (Impostazioni), di solito in basso a destra.
2. Vai su "Avanzate" (Advanced).
3. Attiva "Android Debug Bridge (ADB)".
4. Sotto compare una scritta tipo:  "Connettiti ad Android a 127.0.0.1:5555"
   ANNOTA quel numero (puo' essere 5555, 5565, 5575...). Ti serve al passo 5.
5. Salva le impostazioni (BlueStacks puo' chiederti di riavviarsi: lascialo fare).


PASSO 3 - SCARICA ADB SUL PC (Platform-Tools)
---------------------------------------------
1. Nel browser cerca:  "SDK Platform-Tools download"  e apri il sito ufficiale Android
   (developer.android.com). Scarica "SDK Platform-Tools for Windows".
2. Scompatta lo zip direttamente in C:\
   Alla fine deve esistere questo file:   C:\platform-tools\adb.exe
   (se ti crea C:\platform-tools\platform-tools\adb.exe, sposta la cartella interna su di un livello)


PASSO 4 - PREPARA LA CARTELLA DELLO SCRIPT
------------------------------------------
1. Crea la cartella   C:\syntra
2. Mettici dentro il file   syntra_diagnosi.py   (quello che ti ho mandato).
3. Apri C:\syntra in Esplora file, clicca sulla barra dell'indirizzo in alto, scrivi  cmd
   e premi Invio: si apre il Prompt dei comandi GIA' nella cartella giusta.
4. Controlla che Python ci sia:
      python --version
   Deve rispondere "Python 3.x". (E' lo stesso Python che usi per costruire l'installer.)


PASSO 5 - PRIMA PROVA DI COLLEGAMENTO
-------------------------------------
Nel Prompt dei comandi (cartella C:\syntra), con BlueStacks APERTO:
      C:\platform-tools\adb.exe connect 127.0.0.1:5555
(al posto di 5555 il numero che hai annotato al passo 2.4)
Deve rispondere:  "connected to 127.0.0.1:5555"  (o "already connected").
   -> Se dice "cannot connect" o "refused": BlueStacks non ha ADB attivo (rifai il passo 2) o il
      numero non e' quello giusto.


PASSO 6 - LE TRE LETTURE
------------------------
Sempre nel Prompt dei comandi, sempre con 5555 sostituito dal tuo numero.

A) In Syntra apri un'operazione condivisa (la schermata con utente in alto a destra, asset,
   entrata, TP), poi:
      python syntra_diagnosi.py dettaglio --indirizzo 127.0.0.1:5555

B) Nella STESSA operazione scorri in basso fino a vedere lo Stop Loss, poi:
      python syntra_diagnosi.py dettaglio_sotto --indirizzo 127.0.0.1:5555

C) Torna indietro all'ELENCO delle operazioni condivise (quello dove compaiono le nuove), poi:
      python syntra_diagnosi.py elenco --indirizzo 127.0.0.1:5555

Ogni volta deve scrivere qualcosa come:  "Fatto: 42 testi letti. File in diagnosi_syntra\..."
   -> Se scrive "0 testi letti" o "l'app non espone testi": mandamelo lo stesso, e' proprio
      l'informazione che serve (vorra' dire leggere dallo screenshot).


PASSO 7 - MANDAMI I FILE
------------------------
Apri la cartella  C:\syntra\diagnosi_syntra  : ci sono 9 file
   dettaglio.xml, dettaglio.png, dettaglio_testi.txt
   dettaglio_sotto.xml, dettaglio_sotto.png, dettaglio_sotto_testi.txt
   elenco.xml, elenco.png, elenco_testi.txt
Comprimili (tasto destro sulla cartella -> Comprimi in file ZIP) e mandami lo zip qui in chat.
Se non riesci a mandare lo zip, mandami almeno i tre file _testi.txt e i tre .png.

Attenzione alla privacy: negli screenshot puo' comparire il tuo nome utente o il saldo. Se non
vuoi mandarli, coprili prima; i file .xml e _testi.txt mi servono comunque interi.


SE QUALCOSA NON VA (scrivimi il messaggio ESATTO)
-------------------------------------------------
- "Non trovo adb.exe"          -> controlla che esista C:\platform-tools\adb.exe (passo 3).
- "Nessun emulatore trovato"   -> BlueStacks chiuso, o ADB non attivo, o numero sbagliato.
- "non autorizzato"            -> in BlueStacks compare una richiesta: premi Consenti.
- "python non e' riconosciuto" -> Python non e' nel PATH: reinstallalo spuntando
                                  "Add python.exe to PATH".
- Screenshot nero              -> Syntra blocca gli screenshot: non e' grave, i file .xml bastano.
